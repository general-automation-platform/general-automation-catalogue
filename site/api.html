API reference · GAP 4.6

Everything a script
can call.

Every function is a global: a script calls tap(…), not gap.tap(…). Scripts are modern JavaScript (ES2023) running in GAP's engine on the device.

Conventions

  • Images are integer handles, and 0 means “no image”. openImage() returns 0 for a missing file. Every handle you get must be passed to releaseImage() — they are native memory, not garbage-collected.
  • Some image functions change the image you pass in instead of returning a new one. They are marked in place below.
  • Coordinates are screen pixels, the same space for screenshots and touches. Fractions are rounded.
  • during is a wait after the action, giving the app time to react — not how long a finger is held.
  • Calls marked newer are not in GAP 3.3, the current stable release, so check first: if (typeof gapPerf === 'function') …
  • Calls marked opt-in do nothing until the user switches them on for that script.

start() and stop()

A script defines two globals. The floating bar's Play calls start(settings) through the settings page, and Stop calls stop(). start() usually loops; stop() runs on another thread while it does, so it only needs to clear a flag the loop checks.

index.js
var running = false;

function start(settings = {}) {
  running = true;
  while (running) {
    // look, decide, act
    sleep(500);
  }
}

function stop() {
  running = false;
}

Pause needs nothing from the script: GAP freezes it inside sleep() and inside every touch call (not keycode() or typing()), and it continues from the same spot on resume. After a Stop, new touches from that run are dropped; a drag already in progress can still finish its moveTo() and tapUp().

Optional hooks: define onPause() and onResume() to be called around a pause, and reportIssue(reason, arg) to be called when the user holds the bar's Log button to report a problem. A script can also name itself with const GAP_SCRIPT_ID = '…'.

Matching

CallReturnsWhat it does
findImage(img, template){x, y, score}Where the template best matches, with a score from 0 to 1. x, y is the top-left corner. A template bigger than the image gives {x: -1, y: -1, score: -1}.

Single-colour templates are handled: they are matched a different way so a score of 1.0 still means a perfect match.

Shell: execute()

When no named call does what you need, execute() runs any shell command with the same access adb shell has — am, pm, settings, input, and the rest.

CallReturnsWhat it does
execute(command)opt-instringRuns command and returns its output (stdout and stderr together). "" while the switch is off.

Off until the user allows it: tap the script's card in the Library, tap Settings to open its Script env screen, and turn on Allow shell commands (GAP asks to confirm). On GAP 4.4 and earlier, Script env is the sliders button on the card instead. Scripts signed for GAP Companion always have it. The switch applies at once. Write scripts to carry on without it, and prefer the named calls above — they are faster and always available. The Playground example uses it this way to open a web page.

example
// Open a web page — something no named call does.
var out = execute('am start -a android.intent.action.VIEW -d "https://example.com"');
if (out === '') {
  console.log('Shell is off: open the page yourself, or allow shell commands');
}

Settings and network

A script never names a URL. It ships gap-env.json listing the values it wants; the user fills them in from a button on its Library card, and must switch on Use environment variables and, for requests, Allow network requests. Requests then say "env:KEY", and GAP sends them to the URL the user typed.

CallReturnsWhat it does
getEnv(key)opt-instring | number | boolean | undefinedThe user's value, else the default. undefined while variables are off.
httpClient(method, "env:KEY", body, headers)opt-instringA request that waits for the answer. Error bodies are returned too; "" when refused or failed.
httpRequest(method, "env:KEY", body, headers)opt-innumberA request that returns at once with an id; the answer arrives as a network event.
addNetworkListener(fn) · removeNetworkListener(fn)—fn({id, type, status, body, error, …}) for each step: queued, sent, then done, failed or refused.

Limits: one request at a time, at least a second apart, 30 a minute per key, bodies up to 1 MiB. Settings pages can't use the network at all.

Settings page bridge

A script's index.html runs in GAP's floating window, offline. It talks to the script through JavaScriptInterface, and GAP calls back into it.

onLog(message)you defineEvery console line from the script.
onGapState(json)you defineQuick Bar page only: the run's state, {active, paused, visible, stripHeight}.
onGapMessage(topic)you defineA nudge from the script's other page (settings ↔ Quick Bar).

The language

QuickJS-ng with ES2023: class with private fields, async/await, generators, optional chaining, ??, destructuring, template literals, BigInt, Proxy. Files are classic scripts, so function start(){} lands on the global object; name a file .mjs for module semantics. There is no setTimeout or setInterval.
